# Support

- **Questions and ideas**: open a GitHub Discussion, or an issue if
  Discussions are not enabled yet.
- **Bugs**: use the bug issue form. Include `python -m swage.env` output and
  a minimal reproducer.
- **Build problems**: check `docs/getting-started/troubleshooting.md` first.
  The most common cause is an LLVM install that does not match
  `cmake/llvm-version.txt`.
- **Security**: see `SECURITY.md`. Do not open public issues.

Swage is a spare-time research project with a single maintainer; response
times are best-effort.
